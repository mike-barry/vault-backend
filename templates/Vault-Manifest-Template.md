# Vault-Manifest.md - This Vault's Structure

Markdown knowledge base for <owner>. This manifest is the vault's self-description - its structure tree and areas.

## Structure

PARA layout:

```
vault/
  Projects/        - active work with a defined finish line
  Areas/           - ongoing responsibilities with no finish line
  Resources/       - reference material
    Vault/         - vault conventions, templates, and skills reference
      Guides/      - the agent guide docs this vault operates by
  Archive/         - completed and inactive work
  Inbox/           - catch-all for content that doesn't fit any existing project or area; triaged out, so near-empty is its normal state
```

Every project and area folder contains three standard subfolders:

- **`Inbox/`** - active working docs and in-flight content. Use when working on in-progress tasks or finding a specific artifact.
- **`Corpus/`** - authored, maintained reference for this project's or area's subject. See the folder note's frontmatter for the list of Corpus docs and their load conditions.
- **`Archive/`** - completed artifacts. Use when referencing past or completed work.
