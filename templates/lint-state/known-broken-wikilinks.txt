# an inline '#' starts a trailing comment.

# PATH-SCOPED IGNORES
# A [path:vault/relative/prefix] header starts a scoped section. Names listed under
# that header are suppressed only when the broken link appears in a file whose
# vault-relative path starts with that prefix. Multiple [path:...] sections are allowed.
# Example:
#   [path:Areas/Vault-Dev/]
#   Some-Placeholder-Note    # only suppressed inside Areas/Vault-Dev/
#
# Only add a target here when the broken link is intentional and you want to stop the
# linter flagging it -- e.g. a placeholder note you have not created yet, or a link
# kept for documentation purposes. Real breaks should be fixed, not ignored.
#
# Example:
#   Some-Planned-Note        # placeholder, note intentionally not created yet
